در این پیوست، متن کامل اسکریپت پیاده‌سازی پایتون بخش عملی پایان‌نامه بر بستر کتابخانه جکس (\lr{JAX}) آورده شده است. این پیاده‌سازی شامل دو بخش بنیادین است:
\begin{enumerate}
\item حل‌گر مرجع طیفی فوریه با گام‌زنی نمایی مرتبه چهار (\lr{ETDRK4}) برای تولید داده‌های دقیق اعتبارسنجی و مقایسه،
\item مدل زمان‌پیوسته شبکه عصبی آگاه از فیزیک برای حل مستقیم معادله غیرخطی برگرز به همراه الگوریتم بهینه‌سازی ترکیبی آدام و \lr{L-BFGS}.
\end{enumerate}
