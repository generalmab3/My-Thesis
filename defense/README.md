# اسلایدهای دفاع

اسلایدهای ارائه دفاع پایان‌نامه با بیمر (Beamer) و زی‌پرشین، حدود ۱۹
اسلاید برای ارائه ۱۵ تا ۲۰ دقیقه‌ای.

## ساخت

```bash
cd defense
./build.sh
# یا دو بار:
xelatex slides.tex
```

## Overleaf

محتویات همین پوشه را زیپ و آپلود کنید، کامپایلر را XeLaTeX بگذارید و
فایل اصلی را `slides.tex` انتخاب کنید. (فونت و شکل‌ها داخل پوشه هستند و
چیز دیگری لازم نیست.)
