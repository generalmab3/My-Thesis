# پایان‌نامه کارشناسی علوم کامپیوتر — دانشگاه بناب

**عنوان:** شبکه‌های عصبی آگاه از فیزیک برای حل مسائل مستقیم و معکوس
معادلات دیفرانسیل جزئی غیرخطی

**پژوهشگر:** محمد امیر بابازاد (شماره دانشجویی 1402135104)

**استاد راهنما:** دکتر بابک آذرنوید

این مخزن شامل سورس کامل لاتک پایان‌نامه (با زی‌پرشین) و کد پایتون
پیاده‌سازی (مدل PINN زمان‌پیوسته برای معادله برگرز) است. ساختار و
صفحه‌آرایی مطابق «دستورالعمل تدوین پایان‌نامه‌های دانشگاه بناب» و قالب
پارسا (ایرانداک) تنظیم شده است.

## ساختار پوشه‌ها

```
thesis/
├── thesis.tex        # فایل اصلی (از اینجا کامپایل می‌شود)
├── front/            # صفحات آغازین: عنوان، تقدیم، سپاسگزاری، چکیده، علائم
├── chapters/         # فصل‌های ۱ تا ۵
├── back/             # منابع، واژه‌نامه، پیوست کد، فرم ارزیابی، چکیده انگلیسی
├── figs/             # شکل‌ها (خروجی کد + لوگوی دانشگاه)
├── fonts/            # فونت فارسی وزیرمتن (داخل مخزن، بدون نیاز به نصب)
├── code/             # کد پیاده‌سازی PINN + راهنما
├── build.sh          # اسکریپت ساخت
└── Makefile
```

## پیش‌نیازهای ساخت PDF

- توزیع تک‌لایو (TeX Live 2022 یا جدیدتر) با بسته‌های `xetex` و
  `xepersian` (در نصب کامل تک‌لایو موجود است).
- موتور کامپایل باید **XeLaTeX** باشد (نه pdfLaTeX).
- فونت فارسی داخل پوشه `fonts/` همراه پروژه است و نیازی به نصب
  جداگانه ندارد (فونت وزیرمتن با مجوز OFL).

## روش ساخت

### لینوکس / مک

```bash
cd thesis
./build.sh
# یا
make
```

### ویندوز

کافی است روی فایل `build.bat` دابل‌کلیک کنید (تک‌لایو یا مایک‌تک باید
نصب باشد). اگر مایلید دستی کامپایل کنید: فایل `thesis.tex` را باز کنید،
موتور را روی XeLaTeX بگذارید و دو بار کامپایل کنید.

### Overleaf

۱. همه محتویات پوشه `thesis` را زیپ کنید و در Overleaf آپلود کنید
(یا فایل `overleaf.zip` آماده را آپلود کنید).
۲. از منوی Menu گزینه Compiler را روی **XeLaTeX** بگذارید.
۳. فایل اصلی (Main document) را `thesis.tex` انتخاب کنید.
۴. Recompile را بزنید (دو بار برای کامل شدن فهرست‌ها).

## اجرای بخش عملی (اختیاری)

```bash
cd code
pip install -r requirements.txt
python pinn_burgers.py --mode all
```

خروجی‌ها (معیارها و شکل‌ها) در پوشه `figs/` ذخیره می‌شوند. اعدادی که در
فصل چهارم گزارش شده با همین کد به دست آمده‌اند.

## سفارشی‌سازی

- اگر دانشگاه فونت خاصی (مثل B Mitra یا B Nazanin) را الزامی دانست،
  کافی است دو خط `\settextfont` و `\setdigitfont` در ابتدای فایل
  `thesis.tex` را به نام فونت نصب‌شده روی سیستم خود تغییر دهید.
- مشخصات صفحه عنوان (نام، تاریخ دفاع و...) در فایل
  `front/cover-fa.tex` و `back/cover-en.tex` قابل ویرایش است.

## عیب‌یابی

- خطای `font not found`: مطمئن شوید با XeLaTeX کامپایل می‌کنید و پوشه
  `fonts/` کنار فایل `thesis.tex` قرار دارد.
- خالی بودن فهرست مطالب در کامپایل اول طبیعی است؛ بار دوم کامپایل کنید.
- اگر در Overleaf خطای حافظه گرفتید، پروژه را با Clear Cached Files
  دوباره کامپایل کنید.
