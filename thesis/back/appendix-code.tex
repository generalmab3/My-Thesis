در این پیوست، متن کامل اسکریپت پیاده‌سازی پایتون بخش عملی پایان‌نامه بر بستر کتابخانه جکس (\lr{JAX}) آورده شده است. این پیاده‌سازی شامل سه بخش بنیادین است:
\begin{enumerate}
\item حل‌گر مرجع طیفی فوریه با گام‌زنی نمایی مرتبه چهار (\lr{ETDRK4}) برای تولید داده‌های دقیق اعتبارسنجی؛
\item مدل زمان‌پیوسته شبکه عصبی آگاه از فیزیک برای حل مستقیم معادله برگرز به همراه الگوریتم بهینه‌سازی ترکیبی آدام و \lr{L-BFGS}؛
\item فرمول‌بندی مسئله معکوس برای شناسایی ضرایب فیزیکی معادله در سناریوهای داده تمیز و نویزی.
\end{enumerate}
