# پایان‌نامه کارشناسی علوم کامپیوتر — دانشگاه بناب

**عنوان:** شبکه‌های عصبی آگاه از فیزیک برای حل مسائل مستقیم و معکوس معادلات دیفرانسیل جزئی غیرخطی

**پژوهشگر:** محمد امیر بابازاد (شماره دانشجویی ۱۴۰۲۱۳۵۱۰۴)

**استاد راهنما:** دکتر بابک آذرنوید

این مخزن شامل سورس کامل لاتک پایان‌نامه (با زی‌پرشین) و کد پایتون پیاده‌سازی (مدل PINN زمان‌پیوسته برای معادله برگرز) است. ساختار و صفحه‌آرایی مطابق «دستورالعمل تدوین پایان‌نامه‌های دانشگاه بناب» و قالب پارسا (ایرانداک) تنظیم شده است.

## ساختار پوشه‌ها و فایل‌ها

```
├── thesis.tex        # فایل اصلی پایان‌نامه (کامپایل با XeLaTeX)
├── front/            # صفحات آغازین: عنوان، تقدیم، سپاسگزاری، چکیده، علائم
├── chapters/         # فصل‌های ۱ تا ۵
├── back/             # منابع، واژه‌نامه، پیوست کد، فرم ارزیابی، چکیده انگلیسی
├── figs/             # شکل‌ها و نمودارها (خروجی کد + لوگوی دانشگاه)
├── fonts/            # فونت‌های فارسی وزیرمتن (همراه مخزن)
├── code/             # کد پیاده‌سازی پایتون PINN + راهنما
├── build.sh          # اسکریپت ساخت خودکار لینوکس و مک
├── build.bat         # اسکریپت ساخت ویندوز
└── Makefile          # دستورات ساخت با Make
```

## پیش‌نیازهای ساخت PDF

- توزیع تک‌لایو (TeX Live 2022 یا جدیدتر) یا مایک‌تک به‌همراه بسته‌های `xetex` و `xepersian`.
- موتور کامپایل باید **XeLaTeX** باشد (نه pdfLaTeX).
- فونت‌های فارسی وزیرمتن در پوشه `fonts/` قرار دارند و نیازی به نصب جداگانه در سیستم‌عامل ندارند.

## روش ساخت

### لینوکس / مک

```bash
./build.sh
# یا
make
```

### ویندوز

کافی است روی فایل `build.bat` دابل‌کلیک کنید یا در خط فرمان دستور زیر را اجرا نمایید:
```cmd
build.bat
```

### کامپایل دستی یا در Overleaf

۱. تمام فایل‌ها و پوشه‌های مخزن را در Overleaf بارگذاری کنید.
۲. از منوی Menu گزینه Compiler را روی **XeLaTeX** تنظیم نمایید.
۳. فایل اصلی (Main document) را `thesis.tex` انتخاب کنید.
۴. دکمه Recompile را دو بار بزنید تا کلیه فهرست‌ها، ارجاعات متقابل و مراجع به‌درستی ایجاد شوند.

## اجرای بخش عملی و تولید داده‌ها (اختیاری)

```bash
cd code
pip install -r requirements.txt
python pinn_burgers.py --mode all
```

خروجی‌های عددی و شکل‌های برداری حاصل در پوشه `figs/` بازتولید و ذخیره می‌گردند.
